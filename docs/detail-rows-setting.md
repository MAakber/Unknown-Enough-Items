# 每页卡片行数 — 1.2.9

在 UEI 设置中增加「每页卡片行数」（English: Cards per page）。点击数值按钮
循环选择 1–4 行，默认 2 行；获取途径、制作配方和用途共用此值。设置写入
`General/DetailRowsPerPage` 并自动保存，旧配置首次加载时使用默认值。

更多行时，共用卡片内容按详情面板的可用高度等比缩小；外框宽度和像素边框
保持一致。计算扣除标题、物品摘要、来源分类按钮、实际显示的扫描提示和间距。
详情面板高度受屏幕可用高度限制，调整比例或窗口大小后重新计算。末页仍沿用
同一密度，不放大剩余卡片。默认两行在空间足够时保持原有大小。

获取途径和配方页码按新行数重新计算，保留此前首张卡片所在的新页；设置内
连续调整行数时仍保留该浏览位置。来源补齐沿用已有卡片锚点。行数不改变
物品列表的 60 格分页、搜索、收藏和来源数据；描述补充继续滚动阅读。

此前卡片布局和来源条件见[获取卡片记录](acquisition-card-layout.md)。
本任务的开始备份、构建和安装证据保存在 `artifacts/detail-rows-2026-11-23/`；
开始时源码、Git 差异、1.2.8 DLL 和配置保存在其中的 `baseline/`。

正式版与 Gale 核心的 10 个引用哈希核对通过，编译 0 警告、0 错误。
1,393 项既有回归、实际 API 核对、23 项包自动化测试、版本一致性和差异格式检查
均通过。开始备份中的 58 个其余文件哈希未变；本次仅修改设置、详情分页和
卡片尺寸相关代码及版本说明。

## 验收

- 在设置中切换 1、2、3、4 行，关闭设置后查看获取、制作和用途页的卡片数及页码。
- 浏览靠后的详情页，连续调整行数；原先首张卡片仍在新页，来源补齐不乱跳。
- 调整面板比例和窗口大小；卡片不重叠，图标、悬浮提示和点击目标一致。
- 配方材料、产物、收藏和原版配方跳转正常；描述补充可完整滚动。
- 重新打开物品栏、切存档和重启游戏后，行数设置保留。

编译与离线回归不验证 Unity 的实际排版、点击命中或帧时间。游戏内验收由用户完成。
